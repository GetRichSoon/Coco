When Boss points out any mistake, add it the same day to that team's mistakes file (YouTube: company/youtube/MISTAKES.md, newest at the top, each with a rule). Then make sure a separate checker agent (release-qa, never the maker) checks every new output against that file before it goes out.

**Why:** Boss, 2026-10-22: "when I tell you a mistake you have to note it down, and from next time don't let this type of mistake happen; create an agent for it if you want."

**How to apply:** check videos and other public outputs deeply (a sheet of 40+ frames, the full play, and the metadata), not with a few stills. Related: [[youtube-team-the-flow]], [[quality-promise]].
