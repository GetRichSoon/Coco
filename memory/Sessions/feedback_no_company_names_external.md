When creating anything outside our PC, never use "Fenwick", "Good Space" or "Coco" style names. That covers subdomains, cloud service names, URLs, account and app names. Use the product's own plain name instead, e.g. screentimetracker.workers.dev.

**Why:** Boss, 2026-10-25, right after Nova set the Cloudflare workers.dev subdomain to "fenwicklabs": "don't set Fenwick, Good Space or Coco like names please". It was changed to "screentimetracker".

**How to apply:** Before naming any external resource, pick the product name (no dashes, see [[feedback-no-dash-in-names]]). Internal folders that already use Good Space/Coco names stay as they are.
