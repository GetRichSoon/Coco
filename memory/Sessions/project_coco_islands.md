Founder decisions 2026-10-22: Bloom-style island for the PC inside Coco Lounge Desktop; Coco Halo (apps/nova-island, package com.novahq.novaisland) on the phone. Two separate builds, same Coco Brain. PC unlock: skipped (no sign-in module).

PC (Good Space\Coco\Lounge Desktop): island.html + island-preload.js, window code in main.js ("Coco Island" block). Data: Lounge page pushIsland() after every loadAll, plus liveSessions() (Claude Code). CocoIslandHelper.exe (build-island-helper.cmd) prints song + full-screen state as JSON lines. Hidden only during full screen (shows at the office too, Boss 2026-10-22). Tray: "Coco Island" toggle + module checkboxes. Look test: offscreen harness, not on Boss's screen.

Phone (Coco Halo 1.4.0): exact iPhone behaviour. Black pill in the status bar via an ACCESSIBILITY overlay (IslandAccessibility) — without it the status bar takes taps and draws over the pill; Boss must keep it On. Status-bar state read from a probe APPLICATION_OVERLAY made with applicationContext. Messages stay normal notifications (no double); Coco Lounge alerts become Coco Brain (orange "YES?" pill). Tap opens app, tap again = home. Nord CE 2 (IV2201, ColorOS) reports its cutout at the top left, so the pill stays centred.

Dock (2026-10-22, Boss chose Dock + hide taskbar): dock.html/dock-preload.js, apps = taskbar pinned .lnk files, open dots from helper 'procs'. Helper 'taskbar hide' keeps Shell_TrayWnd hidden and brings it back when Coco quits or dies (stdin EOF). Tray icon is hidden with the taskbar, so settings are on the Dock right-click menu. Over a maximised app the island pill fades and is click-through (Chrome tabs/new-tab); only the 8 px top band + 200 ms dwell opens it. Tests: Lounge Desktop/island-hover.test.js (17).

Final pass 2026-10-22: helper split in CocoIslandHelper.cs + CocoIslandHelperExtras.cs (volume via Core Audio, Wi-Fi scan/connect via WiFiAdapter, Bluetooth paired list, radios, album art, EnumWindows list with hwnd + front). Dock: every app window grouped per app, live previews (desktopCapturer), own pin list in island.json (pins/unpinned), + button, right-click pin/unpin/new/close. Store app icons from the package AppxManifest. getFileIcon is queued with a 2 s limit (it hung the Dock). Errors: userData\island.log. Faster: island springs 600/42, 650/44, 1200/55; dwell 120 ms, leave 250 ms.
