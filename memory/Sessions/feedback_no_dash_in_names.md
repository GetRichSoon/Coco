Do not use "-" in names. This covers app names (no "Unfold — Open Any File", just "Unfold"), the APK file name, and files the apps create. Use underscores instead, e.g. `Images_20261014_045501.pdf` or `page_001.png`.

**Why:** founder instruction, 2026-10-14, while the Unfold file-opener app was being built.

**How to apply:** for every new product, store listing title, build artifact and generated file name, use a plain word or underscores. Existing repo folders and code identifiers can stay as they are; the rule is about names the founder or users see.
