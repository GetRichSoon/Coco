Before starting the next video production or other big build, ask Boss first: what will be made, where it runs (laptop PC or cloud such as GitHub Actions), and roughly how much Claude limit and time it takes. Ask in Coco (app chat: insert a `role='coco'` row in Coco Cloud `chat`) or in whichever terminal or session he is using. Start only after his answer.

**Why:** Boss, 2026-10-21. The Kahani Ghar ep1 render ran on the laptop without him choosing where. He wants to decide (PC vs cloud) before each production.

**How to apply:** Kahani Ghar ep1 stays on the PC (his decision). Future episodes: proposed cloud render via GitHub Actions in GetRichSoon, not set up yet, ask first. Related: [[feedback-claude-is-a-tool]], [[project-youtube-channels-account]].
