# Load in Brave (30 seconds)

1. Open `brave://extensions` in Brave.
2. Turn ON **Developer mode** (top right).
3. Click **Load unpacked** → pick `C:\Users\Lenovo\Good Space\Coco\Extensions\Coco Idea Saver`.
4. Done. On any YouTube video an indigo **Save to Coco** chip appears (drag it anywhere);
   on any page/link/image/selection, right-click → **Save to Coco Notes**.

Needs the Coco heart server running (`Start Coco.cmd` / `npm start` in Good Space\Coco).
If it is off, saves wait in the extension and flush within 5 minutes of it coming back.
