# Setup (Big Boss PC)
One folder, one click. On Shreya's PC:
1. Download this repo: github.com/GetRichSoon/Coco > Code > Download ZIP (or open this folder if Coco is already cloned).
2. Double-click **Setup Big Boss PC.cmd**.
3. Sign in to GitHub once when the browser opens (her account, shreyaahiremath).

What it does (safe to run again): installs Git, Node, GitHub CLI if missing; makes `Good Space\` with `Coco` (this repo), an empty `Coco Vault`; clones `nova-hq` and `shreya-nova-hq`; installs the Coco desktop app and starts it at every logon (+ desktop shortcut); writes her Claude rules; installs the Remote Control watchdog.
Never copies Boss's vault, keys or Safe Keeping.
