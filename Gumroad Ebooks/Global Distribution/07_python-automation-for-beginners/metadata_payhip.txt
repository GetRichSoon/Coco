SAFE BY DESIGN
Scripts that change files have a dry-run mode or a backup step, nothing is deleted automatically, no passwords are stored in code, and the network project respects the public API it uses. The book teaches these habits.

WHAT WAS TESTED
All 25 scripts were run on Windows 11 with Python 3.14.4 (openpyxl 3.1.5, pypdf 7.0.0) on 2026-11-07, and the sample outputs in the book are the real outputs. A smaller compatibility check was run on Python 3.12.12: all 25 compile and show help, and nine representative scripts gave the same results.

WHAT WAS NOT TESTED
macOS and Linux, Windows Task Scheduler, cron and launchd, opening the email drafts in a mail program, opening the Excel files in Excel itself, and OCR for scanned PDFs. The book says so wherever it matters.

FAQ
Q: Do I need to know programming?
A: No. Chapter 3 teaches the basics you need, and every project explains its code.

Q: Which Python version and operating system?
A: Python 3.12 or newer. The scripts were tested on Windows 11. They use portable code and should work on macOS and Linux, but those were not tested.

Q: Do the scripts really work?
A: Every script was run against the sample data included in the download, and the outputs in the book are from those runs. See the "What was tested" section.

Q: Is it safe to run on my files?
A: Use copies first. Scripts that change files have a dry run or backup, and the duplicate finder only reports.

Q: Does it cover web scraping?
A: No. It covers one documented public API and teaches responsible use. It does not teach scraping sites that forbid it.
