# Diagrams for The 90-Day Clinical Licensing Exam Study Plan

Five self-contained SVGs (Georgia, palette navy #0f2238 / cream #f4efe6 / copper #b87333 / teal #3aa6a0), each rendered to PNG with headless Chrome and visually checked. Each only restates something the manuscript already says; no new facts. Insertion points are in `..\manuscript_with_diagrams.md` (an exact copy of the original with only 5 image lines added; verified by removing them and comparing bytes).

| File | Shows | Chapter / where inserted | Why it helps |
|---|---|---|---|
| 01_phases_timeline.svg | The four phases, with bar widths proportional to days (1 to 7, 8 to 63, 64 to 84, 85 to 90) | Ch 10, after the phase table, before "Laying it out" | Readers cannot see that phase 2 is more than half of the plan from a table. |
| 02_block_anatomy.svg | The 90-minute block: 10 retrieve, 55 statements, 20 questions, 5 log | Ch 10, after the block bullet list | The proportions (most time on statements, protected retrieval and question writing) are the method. |
| 03_review_schedule.svg | Grid of weeks studied against weeks reviewed (+1, +3, +6) | Ch 15, after the interval table | A grid makes the expanding gaps visible; the table is a list. |
| 04_pacing_checkpoints.svg | 240-minute bar with the six checkpoints (35, 69, 105, 140, 174, 210) and the 30-minute reserve | Ch 18, after the checkpoint table | Shows where "about 105 minutes at end of section one" sits. |
| 05_behind_triage.svg | Decision flow: two questions, three outcomes, cut order, never-cut list, compressed plan | Ch 21, before "The compressed plan" | The chapter is a decision procedure; a flow is faster to use while demoralised. |

Source consistency checks: the review grid matches the chapter 15 table (weeks 6 to 8 return to phase 3 twice; the grid marks the first return and says so); the pacing numbers match chapter 18; phase 3 "no new statements after day 70" is in chapter 16 (note chapter 14 says day 60: an existing inconsistency, listed in AUDIT.md).

Not diagrammed on purpose: the three scenarios (text reasoning) and the week-by-week phase 2 table (already a table).

Alt text lines in the manuscript copy are short plain descriptions for screen readers. PNG versions are alongside each SVG for platforms or designers that need raster.
